# Security

Please do not report security problems in public issues or pull requests.

Report them privately through [a security advisory](https://github.com/mypulseapi/open-pulse/security/advisories/new). The maintainers will reply there, agree a fix and credit you if you wish.

If you find an API key, credential or customer data committed to this repository, report it the same way so it can be removed and rotated.
